# Biblioteca de templates do Declare Já

Este repositório contém somente modelos de declaração disponibilizados para consulta e download pelo Declare Já.

## Segurança e privacidade

- Não armazena declarações geradas, planilhas, comprovantes ou assinaturas.
- Cada arquivo é verificado por SHA-256 antes de ser importado.
- O download é sempre solicitado pelo usuário; não existe sincronização automática.
- A substituição de um template local cria uma cópia de segurança no computador.

O arquivo `catalog.json` é consumido pelo aplicativo e descreve os modelos disponíveis na pasta `templates`.
